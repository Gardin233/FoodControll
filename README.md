# 简介
为了鼓励玩家尽量不完全依赖原版食物，尽可能制作我使用craftEngine提供的高级食物，于是我制作了这个插件
用于修改原版除蛋糕以外的（我不在乎蛋糕，而且蛋糕的进食是另一种逻辑）食物的饱食度和饱和度。
## 用法
因为我使用1.21.11的paper端，所以这个插件自然是为此服务的，我已经在配置文件中默认添加了所有可食用的食物
的默认配置并按照维基百科的顺序分好了类别
当你第一次成功启动服务端后，生成的配置文件会如下图所示
```yaml
debug: true
foods:
  minecraft:apple:
    nutrition: 2
    saturation: 0.3
  ......
```
所有的食物都应该foods下被编辑，更详细的信息可以在配置文件中查看

debug模式还非常简陋，仅用于我来查看物品名和修改状态
